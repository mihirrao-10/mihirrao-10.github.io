Files: 4-byte little-endian uint16 width and height, followed by 8-bit grayscale pixels.
Gzip files preserve exactly the same payload.

Galaxy fields: grayscale luminance conversion, background removal, and soft edge
feathering. A fine tessellated mesh and weighted particle samples retain the
photographed positions. Depth, parallax, and motion are authored, not measured.
Dark ink represents emitted light in all scenes. Source frames are not time series.

Reproduction: save the four inputs as sun.jpg, saturn.jpg, galaxy.jpg, cluster.jpg;
verify the input hashes above, then run tools/black-geometry/prepare-astronomy.py
with the input directory. The SDO latest URL is mutable: use the recorded frame.
The prep tool requires Pillow and NumPy; the website build does not.

The black-hole silhouette references Gargantua from Interstellar and NASA's
warped-world visualization. No copyrighted film still is included in the site.
