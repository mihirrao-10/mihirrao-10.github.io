Real Analysis

Chapter 1: Sets, Set Operations, and Mathematical Induction

Notes by Mihir Rao

The course has two aims: gaining experience with proofs, and proving statements about real numbers, functions, and limits. We begin with the basic vocabulary of sets and the principle of induction, both of which we will use constantly.

1.1  Basic Set Theory

A set is a collection of objects, called the elements or members of the set. The empty set, denoted $\emptyset$, has no elements. Throughout we use the following standard shorthand. For a set $S$:

  • $a \in S$ — "$a$ is an element of $S$";
  • $a \notin S$ — "$a$ is not an element of $S$";
  • $\forall$ — "for all";
  • $\exists$ — "there exists";
  • $\exists!$ — "there exists a unique";
  • $:=$ — "is defined to be";
  • $\implies$ — "implies";
  • $\iff$ — "if and only if".
Definition [set relations]. Let $A$ and $B$ be sets.
  1. $A$ is a subset of $B$, written $A \subseteq B$, if every element of $A$ is an element of $B$; equivalently, $a \in A \implies a \in B$.
  2. $A$ and $B$ are equal, written $A = B$, if $A \subseteq B$ and $B \subseteq A$.
  3. $A$ is a proper subset of $B$, written $A \subsetneq B$, if $A \subseteq B$ and $A \neq B$.

A common way to specify a set is set-builder notation: $$\{x \in A \mid P(x)\} \qquad \text{or} \qquad \{x \mid P(x)\},$$ read "all $x$ in $A$ satisfying the property $P(x)$." For example, $\{x \mid x \text{ is an even integer}\}$. The following sets recur throughout the course:

  1. the natural numbers $\mathbb{N} = \{1, 2, 3, 4, \ldots\}$;
  2. the integers $\mathbb{Z} = \{0, \pm 1, \pm 2, \pm 3, \ldots\}$;
  3. the rationals $\mathbb{Q} = \left\{ \tfrac{m}{n} \;\middle|\; m, n \in \mathbb{Z},\ n \neq 0 \right\}$;
  4. the real numbers $\mathbb{R}$.

These satisfy $\mathbb{N} \subseteq \mathbb{Z} \subseteq \mathbb{Q} \subseteq \mathbb{R}$. The fourth item raises the central problem of the first part of the course: how do we describe $\mathbb{R}$? We answer this in Lectures 3 and 4.

For sets $A$ and $B$, we define

  • the union $A \cup B = \{x \mid x \in A \text{ or } x \in B\}$;
  • the intersection $A \cap B = \{x \mid x \in A \text{ and } x \in B\}$;
  • the set difference $A \setminus B = \{x \in A \mid x \notin B\}$;
  • the complement $A^c = \{x \mid x \notin A\}$, taken relative to a fixed ambient set;
  • $A$ and $B$ are disjoint if $A \cap B = \emptyset$.

Theorem (De Morgan's Laws). Let $A$, $B$, $C$ be sets. Then
  1. $(B \cup C)^c = B^c \cap C^c$;
  2. $(B \cap C)^c = B^c \cup C^c$;
  3. $A \setminus (B \cup C) = (A \setminus B) \cap (A \setminus C)$;
  4. $A \setminus (B \cap C) = (A \setminus B) \cup (A \setminus C)$.
Proof. We prove (1); the others are similar and are left to the reader. To show $(B \cup C)^c = B^c \cap C^c$, we prove both inclusions. If $x \in (B \cup C)^c$, then $x \notin B \cup C$, so $x \notin B$ and $x \notin C$. Hence $x \in B^c$ and $x \in C^c$, so $x \in B^c \cap C^c$. Conversely, if $x \in B^c \cap C^c$, then $x \notin B$ and $x \notin C$, so $x \notin B \cup C$, i.e. $x \in (B \cup C)^c$.

1.2  Mathematical Induction

The set $\mathbb{N} = \{1, 2, 3, \ldots\}$ carries a natural ordering $1 < 2 < 3 < \cdots$. The following property of this ordering is taken as an axiom.

Definition [well-ordering property of $\mathbb{N}$]. Every nonempty subset $S \subseteq \mathbb{N}$ has a least element: there exists $x \in S$ such that $x \leq y$ for all $y \in S$.

From the well-ordering property we deduce the principle of mathematical induction. The intuition is the standard one: if the first domino in an infinite row falls, and any domino that falls knocks over the next one, then every domino falls.

Theorem (Induction). Let $P(n)$ be a statement depending on $n \in \mathbb{N}$. Suppose
  1. (Base case) $P(1)$ is true, and
  2. (Inductive step) for all $m \in \mathbb{N}$, if $P(m)$ is true then $P(m+1)$ is true.
Then $P(n)$ is true for all $n \in \mathbb{N}$.
Proof. Let $S = \{n \in \mathbb{N} \mid P(n) \text{ is false}\}$. We prove $S = \emptyset$ by contradiction. Suppose $S \neq \emptyset$. By the well-ordering property, $S$ has a least element $m$. Since $P(1)$ is true, $m \neq 1$, so $m > 1$ and $m - 1 \in \mathbb{N}$. Because $m$ is the least element of $S$, $m - 1 \notin S$, i.e. $P(m-1)$ is true. By the inductive step, $P(m)$ is true, so $m \notin S$, contradicting $m \in S$. Hence $S = \emptyset$.
Definition [proof by contradiction]. To prove a statement by contradiction, assume its negation and derive a false statement. By the rules of logic the original statement must then be true. This pattern recurs throughout the course.

1.3  Worked Examples

We illustrate induction with two standard examples.

Theorem (Geometric sum). For all $c \in \mathbb{R}$ with $c \neq 1$ and all $n \in \mathbb{N}$, $$1 + c + c^2 + \cdots + c^n \;=\; \frac{1 - c^{n+1}}{1 - c}.$$
Proof. We induct on $n$. For the base case $n = 1$, the left-hand side is $1 + c$, and the right-hand side is $$\frac{1 - c^2}{1 - c} = \frac{(1 - c)(1 + c)}{1 - c} = 1 + c.$$ For the inductive step, suppose the identity holds for some $k \in \mathbb{N}$. Then $$ \begin{aligned} 1 + c + \cdots + c^k + c^{k+1} &= \frac{1 - c^{k+1}}{1 - c} + c^{k+1} \\ &= \frac{1 - c^{k+1} + c^{k+1}(1 - c)}{1 - c} \\ &= \frac{1 - c^{k+2}}{1 - c}. \end{aligned} $$ By induction, the identity holds for all $n \in \mathbb{N}$.
Theorem (Bernoulli's inequality). For all $c \geq -1$ and all $n \in \mathbb{N}$, $$(1 + c)^n \;\geq\; 1 + nc.$$
Proof. We induct on $n$. The case $n = 1$ reduces to $(1 + c)^1 = 1 + 1 \cdot c$, which holds with equality. Suppose $(1 + c)^m \geq 1 + mc$. Since $c \geq -1$, the factor $1 + c$ is non-negative, so we may multiply the inequality by it: $$(1+c)^{m+1} \;=\; (1+c)^m\,(1+c) \;\geq\; (1 + mc)(1 + c) \;=\; 1 + (m+1)c + mc^2 \;\geq\; 1 + (m+1)c,$$ where the last inequality uses $mc^2 \geq 0$. By induction, the inequality holds for all $n \in \mathbb{N}$.
